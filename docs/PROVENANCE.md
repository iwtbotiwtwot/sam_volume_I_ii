## What is selected and what is omitted

The export retains mathematical operands, derivations, reader sources,
certificates, native inputs/outputs, task receipts, completion/custody records,
independent verification code and the scientific source-session adapter
snapshots used by the provenance audit. Source-session inputs, outputs and
executed scientific-code identities remain distinguishable from installed
native primitives.

The export omits the global research SQLite corpora and their full index
inventories, unrelated runtime/topology engineering, installed runtime/core
implementation snapshots, repeated monitoring bulk and mutable authority
preimages. The omission list records each original path, reason, byte count
and hash. Used retrieval receipts and source excerpts remain available.

Original custody/manifests describe their original larger scopes. Their hashes
are historical evidence; they do not certify that every named file is present
in this repository. The selected manifest is the portable byte inventory.
No omitted artifact is silently loaded from the original machine.

## Reproduction adaptations

`scripts/reproduce.py` implements a compact independent reference calculation
on repository operands. `scripts/verify_native.py` verifies the selected bytes
and then stages a disposable copy to replay the retained physical and
source-to-field checkers. Regenerated summaries do not overwrite frozen files.

Seven physical checks run with their original code unchanged. One legacy
cycle check originally hashes the entire research SQLite database. As that
corpus is omitted, a narrowly checked AST adaptation changes that one predicate
to compare its retained index digest with the launch configuration and original
manifest. The original checker bytes remain preserved. The report explicitly
sets `legacy_cycle_index_bytes_checked: false` and records one portable
adaptation. It does **not** claim to rehash the omitted corpus.

The nine source-to-field offline checks run with their retained code unchanged;
the original root archive-manifest step is skipped because the public selected
manifest, rather than the original larger ZIP inventory, is verified first.
These adaptations change packaging/custody scope, not mathematical formulas,
native intervals or original receipts. See [native evidence](NATIVE_EVIDENCE.md)
for exact count and replay distinctions.
