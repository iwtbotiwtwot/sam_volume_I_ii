# Retained native evidence and independent replay

The repository ships selected original scientific evidence from the completed
Chapter II physical-development and source-to-field campaigns. It supplies
ordinary Python verification of their retained returns. The public command
does not launch Duck, install a scientific engine or recreate the original
runtime.

```bash
python scripts/verify_native.py --integrity-only
python scripts/verify_native.py
```

The default full report is `build/native_verification.json`.

## Isolated execution preserves the original bytes

The wrapper first verifies the selected inventory and safe paths. It copies
the required retained tree into a disposable location and replays the original
checkers there, so regenerated results do not overwrite frozen evidence.
Historical paths resolve through the portable retained layout; omitted files
cannot be read from an existing SAM installation as fallback.

There are eight physical checks and nine source-to-field checks. Seven
physical scripts and all nine source-to-field scripts run with their original
code unchanged. A narrowly declared adaptation handles the omitted research
database as described below. Original checker files remain preserved even
where the staged execution requires that adaptation.

## The omitted global-index check is explicitly narrower

The original physical cycle checker includes one predicate that hashes the
entire research SQLite index. The selected public export omits those global
corpora and their full index inventories. It retains the used local retrieval
receipts, source excerpts, launch configuration and original digest metadata.

A strict AST adaptation replaces that one legacy predicate in the staged copy.
It verifies agreement of the retained index digest with the launch
configuration and original manifest, rather than opening the omitted database.
The full report records:

```text
legacy_cycle_index_bytes_checked: false
portable_adaptations: 1
```

This is receipt/digest consistency; it is not a fresh byte-hash verification of
the global corpus. The mathematical operations, source operands, certified
returns and readback algorithms are unchanged. The adaptation fails if the
expected legacy predicate cannot be identified exactly.

The original source-to-field reproduction command is run with
`--skip-manifest`: the public selected-byte manifest has already been verified,
and the original larger ZIP inventory includes deliberately unshipped files.
No claim is made that the entire original archive or global runtime tree is
revalidated by a selected clone.

## Original and selected custody scopes

[`evidence/EXPORT.json`](../evidence/EXPORT.json) identifies both source ZIPs
and enumerates omissions with their original names, sizes, hashes and reasons.
Unrelated topology/runtime engineering, installed engine implementation
snapshots, monitoring bulk and mutable authority preimages are outside this
scientific export. Fourteen scientific source-point adapter-code snapshots
needed by the source-session audit remain included.

Original manifests and custody reports retain their larger historical scope.
They are not rewritten to pretend that every original path ships publicly.
Likewise, a native task builder can refer to the qualified external installation
without becoming a standalone engine. The portable entry points are the
repository's `scripts/` commands.

## Scientific interpretation

The retained calculations establish source-law and rank certificates, protocol
identities, independently enclosed receiver consequences and custody under
their stated assumptions. The continuum proof, source-incidence assignments,
physical calibration and apparatus requirements remain separately described.
The native evidence is calculation evidence; expectation-value sample counts
in the chapter refer to proposed experimental measurement protocols.
