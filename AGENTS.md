# Chapter II repository guidance

This is the standalone manuscript and reproducibility repository for Volume I,
Chapter II, *Retention, accumulation, and the finite ledger*. Preserve existing
user changes and work within the requested chapter scope.

- `manuscript/` contains the reviewed 24-page, 48-section reader and editable
  sources. Its first 40 sections preserve the preceding Chapter II reader.
- Frozen evidence in `evidence/` is provenance. Preserve its bytes and hashes;
  changed science requires a separately identified successor.
- Independent Python reconstruction, retained native-output verification,
  analytical proofs and apparatus requirements are different forms of evidence.
  Identify which each result uses. The public commands start no native workers.
- Keep repository-relative execution portable. Historical absolute paths in
  frozen records are identifiers; never read unbundled host files as fallback.
- Retain signed source couplings, the complete source, both field polarizations,
  both counterterms, original common phase, source metric and hidden complement.
- The actual seven-dimensional spin span has residual rank two for all 54
  preparations. The smallest invariant closure remains open; do not call the
  seven-dimensional enlargement, the rank lower bounds or the large invariant
  upper space a stabilized minimum.
- A matched single lane is a two-level system. The finite-sample discriminator
  addresses closed autonomous two-state dynamics with a fixed linear receiver;
  it does not exclude arbitrary driven/open two-state or generic multilevel models.
- Eight expectation samples require repeated preparations. Keep sampling,
  calibration, leakage, timing, disturbance, work and phase-turn records explicit.
- Spatial localization, units, source incidence and external couplings remain
  declared receiving assignments where the chapter says so. Do not import later
  Chapter III results into this frozen Chapter II edition.
- Run scientific tests, reproduction, retained-evidence verification and asset
  verification for relevant changes. Rebuild and visually inspect manuscript edits.
- Preserve MIT software and CC BY 4.0 manuscript/documentation/original research
  licensing, with the third-party exceptions in `docs/LICENSING.md`.
- Do not introduce a replacement Duck runtime, unrelated campaign, invented DOI,
  measured calibration or unperformed experiment.
