# Contributing

Sean Brady is the originator and conceptual director. OpenAI ChatGPT and Codex
are AI research collaborators and co-authors.

Original software contributions use MIT; original manuscript, documentation and
research-material contributions use CC BY 4.0. Preserve third-party notices and
identify separately licensed contributions. See [licensing](docs/LICENSING.md)
and [author roles](AUTHORS.md).

Keep original source laws, declared receiving assignments, mathematical
deductions, native returns, independent verification and physical measurements
identifiable in each change. Existing receipts and original source artifacts
remain historical records. A corrected or extended result gets a new binding
and an explanation of what it supersedes.

Before proposing a change:

1. Run `python -m unittest discover -s tests -v`.
2. Run `python scripts/reproduce.py`, `python scripts/verify_native.py` and
   `python scripts/verify_repository.py`.
3. Explain the changed scientific statement, operands, source binding,
   verification and remaining assumptions. Never replace expected evidence to
   conceal a failed check.
4. For manuscript changes, rebuild/check the PDF and visually inspect every
   changed page. Explain any intentional change to the 24-page, 48-section scope.
5. Keep generated reports in `build/`. Do not add credentials, virtual
   environments, caches, unrelated project files or a native runtime.

Historical absolute paths in frozen records are provenance. New executable
paths must resolve through the bundled, verified mapping. Document whether a
command regenerates a calculation or independently checks a retained result.

In particular preserve these distinctions: signed Write phase, actual current
phase and reference phase; positive displacement payment and signed total
energy change; current-visible and current-invisible energy; rank lower bound
and stabilized closure; expectation values and experimental shots; and a chosen
spatial source/coupling and its derivation from the original dynamics.
